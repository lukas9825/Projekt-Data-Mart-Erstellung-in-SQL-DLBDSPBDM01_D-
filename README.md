## Installation
1. Zunächst eine MariaDB 13.0 Server-Instanz aufsetzen/ auswählen und .SQL-Datei herunterladen.
2. Terminal-/ Shell-Fenster öffnen und auf dem Datenbankserver anmelden
3. Heruntergeladene Datei auf Server ausführen mit <source "Pfad-zur-Datei";>
4. Fertig

Die Datenbank wird durch die SQL-Datei erstellt, muss also vorher nicht selbst gemacht werden.
Der Pfad zur Datei darf keine Leerzeichen enthalten :)
